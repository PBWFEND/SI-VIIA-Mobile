# Tugas 4 — Dokumen Kebutuhan Kantin Kampus

## Deskripsi

Kantin Kampus merupakan aplikasi sederhana yang membantu mahasiswa melihat daftar menu makanan dan minuman, mencari menu berdasarkan nama, melihat harga, serta mengetahui ketersediaan menu. Dokumen Tugas 4 ini berisi analisis kebutuhan aplikasi, user persona, kebutuhan fungsional dan nonfungsional, prioritas fitur menggunakan metode MoSCoW, pemetaan kebutuhan ke antarmuka, serta diagram user flow.

## Refleksi Pengerjaan

Melalui tugas ini, saya memahami pentingnya mengidentifikasi kebutuhan pengguna sebelum mengembangkan sebuah aplikasi. Saya belajar menyusun kebutuhan fungsional dan nonfungsional, menentukan prioritas fitur menggunakan MoSCoW, serta menggambarkan alur pengguna melalui user flow. Saya menyadari bahwa perancangan kebutuhan yang jelas dapat membantu proses pengembangan aplikasi agar lebih terarah dan sesuai dengan kebutuhan pengguna.
