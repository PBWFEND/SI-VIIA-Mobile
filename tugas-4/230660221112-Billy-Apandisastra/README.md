# Tugas 4: Dokumen Kebutuhan dan User Flow - SI Perpustakaan

Dokumen ini berisi analisis kebutuhan sistem untuk aplikasi SI Perpustakaan Mobile, mulai dari penentuan user persona, pengumpulan kebutuhan fungsional dan nonfungsional, hingga pemetaan user flow dan rancangan antarmuka awal.

**Refleksi:**
Bagian analisis yang paling sulit bagi saya adalah menetapkan prioritas MoSCoW karena saya cenderung menganggap semua fitur sangat penting untuk pengguna. Memisahkan antara "Must Have" dan "Should Have" memaksa saya berpikir lebih kritis tentang batasan minimum sebuah aplikasi agar dapat beroperasi menyelesaikan masalah inti. Selain itu, merumuskan kebutuhan nonfungsional dengan ukuran yang spesifik dan terukur juga menjadi tantangan karena tidak bisa sekadar menggunakan kata sifat seperti "cepat" atau "bagus".
