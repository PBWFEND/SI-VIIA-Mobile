Aplikasi: MoneyTrack Mahasiswa

Tugas ini berisi analisis kebutuhan aplikasi mobile meliputi deskripsi aplikasi, user persona, kebutuhan fungsional dan nonfungsional, prioritas fitur, user flow, serta pemetaan kebutuhan ke antarmuka.

## Refleksi

Bagian yang paling sulit saya tentukan adalah kebutuhan fungsional karena harus memastikan setiap fitur memiliki tujuan yang jelas bagi pengguna. Penentuan prioritas MoSCoW juga membutuhkan pertimbangan agar fitur utama tidak terlalu banyak. Penyusunan user flow menjadi lebih mudah setelah kebutuhan pengguna dan fitur aplikasi ditentukan.
