# Tugas 3 - Halaman Aplikasi Sederhana

## Nama Aplikasi

Perpustakaan Kampus

## Deskripsi

Aplikasi ini merupakan halaman sederhana Perpustakaan Kampus
yang digunakan untuk menampilkan katalog buku. Halaman ini
menampilkan judul buku, kategori, dan status ketersediaan buku.

## Widget yang Digunakan

- MaterialApp
- Scaffold
- AppBar
- Column
- Row
- Padding
- Expanded
- ListView.builder
- Card
- ListTile
- FloatingActionButton

## Data Buku

1. Pemrograman Dart - Teknologi - Tersedia
2. Dasar Sistem Informasi - Sistem Informasi - Tersedia
3. UI/UX Design - Desain - Tersedia
4. Basis Data - Teknologi - Habis

## Widget Tree

Widget tree menggambarkan struktur halaman mulai dari
MaterialApp, Scaffold, AppBar, body, Column, Row, Padding,
Expanded, ListView.builder, Card, dan ListTile.

## Refleksi

Widget yang paling sulit saya rangkai adalah ListView.builder
karena harus memahami hubungan antara data buku dengan widget
yang ditampilkan. Saya juga perlu menggunakan Expanded karena
ListView berada di dalam Column. Setelah memahami widget tree,
saya menjadi lebih mudah memahami posisi setiap widget dalam
halaman aplikasi.
