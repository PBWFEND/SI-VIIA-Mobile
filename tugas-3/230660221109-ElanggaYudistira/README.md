## Nama Aplikasi
MoneyTrack Mahasiswa

## Deskripsi
MoneyTrack Mahasiswa adalah halaman aplikasi bergerak sederhana untuk membantu mahasiswa melihat informasi keuangan berupa pemasukan, pengeluaran, dan daftar transaksi. Halaman ini dibuat menggunakan struktur MaterialApp, Scaffold, Column, Row, Padding, dan ListView.builder.

## Domain Sistem Informasi
Manajemen Keuangan Mahasiswa.

## Refleksi
Widget layout yang paling sulit saya rangkai adalah ListView.builder karena membutuhkan pemahaman tentang penampilan data secara berulang. Penggunaan Expanded perlu diperhatikan agar halaman tidak mengalami error overflow. Kombinasi Column, Row, dan ListView membuat tampilan aplikasi lebih terstruktur.
