## Deskripsi

Tugas ini merupakan pengembangan aplikasi Penjualan Warung dengan mengintegrasikan REST API untuk mengambil dan mengirim data. Aplikasi menerapkan proses GET untuk mengambil data dari API dan POST untuk mengirim data, serta menampilkan kondisi loading, success, dan error.

## Deklarasi Penggunaan AI

AI digunakan sebagai alat bantu pembelajaran untuk memahami konsep REST API, asynchronous programming, parsing JSON, dan penanganan error. Kode yang diperoleh melalui bantuan AI dipelajari, disesuaikan, dan diuji kembali oleh mahasiswa.

## Refleksi

Bagian yang paling menantang dalam pengerjaan tugas ini adalah memahami proses asynchronous programming ketika aplikasi mengambil dan mengirim data melalui REST API. Saya perlu memahami bagaimana data JSON diubah menjadi objek Dart serta bagaimana aplikasi menangani kondisi loading, keberhasilan, dan kegagalan permintaan. Melalui pengerjaan dan pengujian aplikasi, saya belajar bahwa pemisahan service API dari tampilan membantu membuat kode lebih terstruktur dan mudah dipahami.
