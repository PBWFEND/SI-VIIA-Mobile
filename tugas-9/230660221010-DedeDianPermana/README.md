## Nama Aplikasi

**SiRuang Kampus - Sistem Informasi Peminjaman Ruang Kelas**

## Deskripsi

Tugas ini mengimplementasikan integrasi REST API pada aplikasi SiRuang Kampus menggunakan Flutter dan package HTTP. Aplikasi menerapkan metode GET untuk mengambil data dan POST untuk mengirim data peminjaman ruangan melalui layanan JSONPlaceholder.

| Nama File | Keterangan |

Melalui pengerjaan tugas ini, saya memahami cara mengintegrasikan REST API ke dalam aplikasi Flutter menggunakan metode GET untuk mengambil data dan POST untuk mengirim data dalam format JSON, serta mempelajari penerapan loading, penanganan error, timeout, dan retry agar aplikasi dapat berjalan dengan lebih baik dan memberikan pengalaman yang nyaman bagi pengguna.
