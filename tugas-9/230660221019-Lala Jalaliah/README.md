## Deskripsi

Tugas ini mengimplementasikan REST API pada aplikasi Pengelolaan Surat Masuk UKM menggunakan Flutter. API yang digunakan adalah JSONPlaceholder dengan metode GET untuk mengambil data dan POST untuk mengirim data surat.

## Fitur

- Mengambil data surat menggunakan GET.
- Mengirim surat baru menggunakan POST.
- Mengubah data JSON menjadi objek Dart.
- Menampilkan kondisi loading, berhasil, dan error.
- Menyediakan tombol untuk mencoba kembali ketika terjadi kesalahan.
