## Refleksi

Bagian yang paling sulit saya tetapkan adalah prioritas MoSCoW karena setiap fitur terasa berguna bagi mahasiswa maupun pustakawan. Saya membatasi fitur Must have pada alur inti pencarian, pemeriksaan, peminjaman, dan pemantauan buku agar tujuan utama aplikasi tetap terukur. Saya juga perlu memastikan setiap cabang gagal pada user flow memiliki tindak lanjut yang jelas, bukan berhenti tanpa solusi.
