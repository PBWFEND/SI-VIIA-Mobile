## Deskripsi

Tugas ini mengimplementasikan navigasi antarhalaman pada aplikasi inventaris menggunakan named routes, `Navigator.pushNamed`, dan `Navigator.pop`. Halaman detail menerima data barang melalui route arguments. Formulir transaksi menggunakan `Form`, `GlobalKey<FormState>`, validasi input, `TextEditingController`, dan `SnackBar` sebagai umpan balik setelah data valid dikirim.
