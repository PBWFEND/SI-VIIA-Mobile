
# Refleksi Penggunaan AI

Dalam pengerjaan Tugas 10, saya menggunakan AI sebagai alat bantu untuk memahami konsep integrasi REST API, menyusun struktur folder Flutter, membuat model data, service API, dan halaman tampilan integrasi.

## 2. Pemahaman dan Pengujian

Saya mempelajari kembali kode yang digunakan, memahami fungsi setiap bagian, serta melakukan pengujian aplikasi menggunakan Flutter. Saya juga menjalankan perintah `flutter analyze` untuk memeriksa kode program.

## 3. Hasil Pembelajaran

Melalui tugas ini, saya memahami cara mengambil data dari dua endpoint REST API, mengubah JSON menjadi model Dart, dan menggabungkan data berdasarkan identifier `userId`.

## 4. Kesimpulan

AI digunakan sebagai pendamping pembelajaran, bukan sebagai pengganti pemahaman. Saya tetap melakukan pemeriksaan, penyesuaian, dan pengujian terhadap kode yang digunakan dalam aplikasi.
