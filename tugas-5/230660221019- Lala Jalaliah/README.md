## Deskripsi

Tugas ini membuat prototipe UI/UX aplikasi Pengelolaan Surat Masuk UKM untuk membantu anggota atau pengurus UKM dan sekretaris dalam mencatat serta memeriksa surat masuk. Prototipe menampilkan daftar surat, informasi pengirim, status pemeriksaan, dan tombol untuk menambahkan surat. Implementasi dibuat menggunakan Flutter dengan Material 3.
