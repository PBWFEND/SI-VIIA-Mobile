# Catatan Keputusan UI/UX

| Keputusan | Pilihan Anda | Alasan (merujuk kebutuhan/persona/prinsip) |
| :--- | :--- | :--- |
| **Warna benih** | Indigo (`Colors.indigo`) | Memberikan kesan profesional, tenang, dan akademis yang cocok dengan persona mahasiswa yang sedang mencari referensi studi. |
| **Bentuk status** | *Pill/Container* membulat di sisi kanan | Menonjolkan informasi ketersediaan (F-01) agar langsung terlihat saat pengguna melakukan proses *scanning* secara visual. |
| **Posisi aksi utama** | `FloatingActionButton.extended` di kanan bawah | Posisi ergonomis untuk dijangkau jempol (sesuai konteks penggunaan mobile sambil memegang buku/berjalan). |
| **Hierarki teks** | Judul tebal, kategori abu-abu di bawahnya | Memudahkan mata pengguna membedakan mana judul utama buku dan mana meta-datanya tanpa kebingungan. |
