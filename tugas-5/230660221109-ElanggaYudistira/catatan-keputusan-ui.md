# Catatan Keputusan UI/UX

| Keputusan | Pilihan | Alasan |
|---|---|---|
| Warna tema | Hijau menggunakan ThemeData | Sesuai konsep keuangan dan memberikan kesan stabil |
| Bentuk status | Teks status berwarna | Membantu pengguna membedakan kondisi transaksi |
| Posisi aksi utama | FloatingActionButton di kanan bawah | Mudah dijangkau saat ingin menambah transaksi |
| Hierarki teks | Saldo dibuat lebih menonjol | Informasi utama harus cepat terlihat pengguna |
