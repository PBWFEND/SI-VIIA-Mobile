# Catatan Keputusan UI/UX

| Keputusan | Pilihan Anda | Alasan (merujuk kebutuhan/persona/prinsip) |
| :--- | :--- | :--- |
| **Warna benih (*Seed Color*)** | Biru Nila (*Indigo*) | Memberikan kesan profesional dan resmi untuk organisasi, serta memiliki tingkat kontras yang tinggi untuk visibilitas di luar ruangan saat Budi (Persona 1) mengakses aplikasi di lapangan. |
| **Bentuk status** | *Chip* kapsul melengkung penuh | Membedakan secara visual antara teks informasi biasa (judul/waktu) dengan elemen indikator, sehingga pengguna dapat memindai status acara (Segera/Selesai) dalam hitungan detik (*Sesi penggunaan singkat*). |
| **Posisi aksi utama** | Kanan Bawah (*FloatingActionButton.extended*) | Sesuai dengan prinsip ergonomi jempol kanan (mayoritas pengguna). Memudahkan Budi memencet tombol *Scan QR* dengan satu tangan sambil berjalan menuju ruang acara tanpa perlu meregangkan jari ke atas layar. |
| **Hierarki teks** | Judul tebal (16pt), detail sekunder abu-abu (14pt) | Membantu pengguna membedakan mana informasi krusial (nama kegiatan) dan informasi pendukung (waktu/lokasi) agar antarmuka tidak terlihat menumpuk (*Layar kecil*). |
