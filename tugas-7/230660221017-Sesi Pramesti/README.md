# SI-FASKAM – Sistem Informasi Fasilitas Kampus

**Nama:** Sesi Prasmesti  
**Program Studi:** Sistem Informasi  
**Mata Kuliah:** Pemrograman Aplikasi Bergerak (PAB)

## Deskripsi
SI-FASKAM merupakan aplikasi berbasis Flutter untuk membantu mahasiswa menyampaikan pengaduan fasilitas kampus.

## Fitur
- Tambah pengaduan
- Lihat daftar dan detail pengaduan
- Edit dan hapus pengaduan
- Ubah status pengaduan
- Cari pengaduan


## Refleksi
Melalui pembuatan aplikasi SI-FASKAM, saya belajar memahami penerapan CRUD menggunakan Flutter, mengelola data dengan List, serta menggunakan StatefulWidget dan setState() untuk memperbarui tampilan aplikasi. Saya juga belajar membuat fitur tambah, edit, hapus, dan menampilkan data pengaduan.
