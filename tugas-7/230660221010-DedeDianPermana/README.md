\## 1. Deskripsi Aplikasi



SiRuang Kampus merupakan aplikasi sistem informasi peminjaman ruang kelas yang dikembangkan untuk membantu mahasiswa mengajukan peminjaman ruangan dan melihat informasi peminjaman. Pada Tugas 7, aplikasi dikembangkan menjadi MVP awal dengan menggunakan data lokal. Fitur yang diterapkan meliputi penambahan, penampilan, pengubahan, dan penghapusan data peminjaman.



\## 2. Daftar File

\## 3. Refleksi Pengerjaan



Bagian tersulit dalam pengerjaan tugas ini adalah memastikan setiap atribut pada model data sesuai dengan kebutuhan fungsional yang telah ditentukan pada Tugas 4. Saya perlu memastikan operasi Create, Read, Update, dan Delete menggunakan atribut serta ID yang konsisten agar data dapat dikelola dengan benar. Hal ini penting karena kesesuaian antara model data, proses CRUD, dan kebutuhan sistem akan memengaruhi ketepatan fungsi aplikasi SiRuang Kampus.
