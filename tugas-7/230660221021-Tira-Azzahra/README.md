## Deskripsi Singkat
Aplikasi ini mengimplementasikan pengelolaan data lokal (CRUD) menggunakan `StatefulWidget` dan `setState` pada Flutter tanpa package tambahan.

## Refleksi
Bagian yang paling sulit dipertahankan konsistensinya adalah memastikan setiap field pada model data selaras dengan kebutuhan yang telah didefinisikan pada Tugas 4. Selain itu, memastikan sinkronisasi antara perubahan state dan tampilan antarmuka memerlukan ketelitian dalam pemanggilan `setState`. Hal ini penting agar seluruh aksi pengguna seperti Create, Update, dan Delete tercermin secara instan pada antarmuka.
