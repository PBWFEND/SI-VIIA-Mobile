## Deskripsi

Folder ini berisi hasil pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pemrograman Aplikasi Bergerak. Pengerjaan terdiri dari tes konsep dan laporan evaluasi perkembangan proyek aplikasi SI-FASKAM.

SI-FASKAM merupakan aplikasi yang dirancang untuk membantu mahasiswa menyampaikan pengaduan mengenai fasilitas kampus yang mengalami kerusakan atau membutuhkan perbaikan.
