## Deskripsi Tugas
Repositori ini memuat berkas pengumpulan Ujian Tengah Semester (UTS) untuk mata kuliah Pemrograman Aplikasi Bergerak. Artefak mencakup jawaban tes konsep esai (`tes-konsep-uts.md`), laporan progress project (`laporan-progress-uts.md`), tangkapan layar antarmuka aplikasi, serta dokumentasi integrasi Milestone M1 hingga M3.

## Refleksi
Bagian yang paling sulit dipertahankan konsistensinya adalah menyelaraskan antara rancangan dokumen kebutuhan awal dengan implementasi nyata pengelolaan data CRUD lokal dan struktur navigasi. Hal ini karena proses pengembangan aplikasi bergerak menuntut penyesuaian logika *state* secara berulang ketika diuji langsung pada perangkat atau simulasi web. Melalui evaluasi tengah semester ini, saya belajar pentingnya menjaga keterlacakan dari analisis kebutuhan pengguna hingga kode program agar fungsionalitas sistem tetap utuh.
