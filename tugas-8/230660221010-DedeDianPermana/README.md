\## Deskripsi Tugas



Tugas 8 merupakan kegiatan Ujian Tengah Semester (UTS) yang bertujuan untuk menguji pemahaman mengenai konsep pengembangan aplikasi mobile menggunakan Flutter dan bahasa pemrograman Dart.



Tugas ini mencakup pembahasan konsep dasar Dart, widget Flutter, kebutuhan aplikasi, UI/UX, navigasi, pengelolaan state, operasi CRUD, serta penyimpanan data lokal.



\## Proyek yang Dikembangkan



Proyek yang dikembangkan adalah \*\*SiRuang Kampus\*\*, yaitu aplikasi sistem informasi peminjaman ruang kelas di lingkungan kampus.



Aplikasi ini dirancang untuk membantu mahasiswa melihat daftar dan ketersediaan ruangan serta mengajukan peminjaman ruang untuk kegiatan perkuliahan, diskusi kelompok, dan kegiatan organisasi.
